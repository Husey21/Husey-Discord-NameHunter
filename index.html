Cloudflare Worker — Proxy Discord

Déploie ce Worker sur Cloudflare Workers (gratuit, 100k req/jour). Ajoute ton token Discord dans les Variables d'environnement, puis entre l'URL du Worker dans l'onglet Proxy.

1. Crée un Worker sur workers.cloudflare.com
2. Colle ce code dans l'éditeur
3. Settings → Variables → ajoute DISCORD_TOKEN (ton user token)
4. Copie l'URL du Worker (ex: https://xxxx.workers.dev) → colle /check dans Name Hunter
